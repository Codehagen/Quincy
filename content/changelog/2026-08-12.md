## The chat can finally read the tables the pages read

The README calls the chat the primary interface, and it was the one surface
that could not name a single riff. It now reads riffs, angles, drafts, the
lineup, channels and sources, and can draft an angle through the same action
the button uses. Nothing in it approves, schedules or publishes.

## Somebody hears about it when the scheduled work stops

A cron that fails quietly is the expensive one: approved posts sit queued until
the window closes and are marked missed, and missed is terminal. All four jobs
now send an email when they fail, at most one per job per hour.

## A captured timezone takes effect on the next render

Anyone who signed up with Google had their zone read on the first visit and
written straight to the row, which the signed session cookie did not know

## The editor says when the draft is your own hook

When drafting fails, the angle's hook is written into the body on purpose, so
there is a line to work from rather than an error. /riffs said so and /drafts
did not, so an 89-character hook sat in the editor looking like writing. The
notice clears itself on the first keystroke.

## The deploy log says what this Quincy can do

Every optional variable already degrades honestly — Google hides a button,
Stripe hides Subscribe — and none of it was visible to the person who just
deployed. Boot now prints three required variables and nine capabilities, and
for each one that is off, the consequence rather than the variable name.
