## Quincy said it could see the account, not that it had read nothing of it

Asked whether it could see your past posts, Quincy answered that it had access
to the connected X account and stopped there. True, and useless: it had read
none of it, and one button on /sources would have changed that. It now says how
much of the corpus it holds, and where the button is. It also stopped writing
the handle as `@@CodeHagen`.

## Luna at low effort, and the reason is measured rather than argued

Three models were run on the same task with the same material. The cheapest
was also the fastest and wrote the sharpest hooks; the dearest cost 25x for
output that was not better. Reasoning effort is now set at every call site
instead of none of them.

## A cheap model needs its price in the table before it needs a deploy

The price table held one model and everything else fell through to the dearest
one. That table is not decoration — it is what the daily spend ceiling
enforces, so a $10 day would have stopped at about thirty cents of real spend.
Chat and drafting also stop sharing one setting, so going cheap on the
conversation no longer goes cheap on what you publish.

## A capture that gets killed now leaves nothing instead of a corpse

The first capture from the chat ran four model calls in one turn and was cut
off at sixty seconds, leaving a riff that said `working` forever. The budget
goes to 120 seconds, and the angles are now asked for before the row is
written, so a kill leaves nothing behind rather than something stranded.

## The chat can put material on the desk, not only read it

You paste a script into the Studio and Quincy could only describe the desk,
never put anything on it — so it offered to write the post inside the
conversation, where it can never be approved or published. Pasted material now
enters through the same door as everything else.

## The desk offered a scrap Quincy had lost 42 hours earlier

The riff card had been honest about a stalled scrap for a while: past four
minutes it says Quincy may have lost this one. The Studio greeting and the
chat had not caught up, so both were offering to draft from material no angle
was ever coming for.

## Nobody but one laptop could install this repository

An animation inspector nothing in the product uses came from a private
registry, so every contributor cloning the public repo hit the same 401 that
CI did. It is optional now, and the code that loads it disappears when the
package is absent.
